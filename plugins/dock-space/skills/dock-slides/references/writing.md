# Writing examples

Load when you write body text for an argument, report or pitch and want the rules on the core page shown.

| Before                           | After                                      | Fixed                           |
| -------------------------------- | ------------------------------------------ | ------------------------------- |
| 賦能團隊，全面提升協作效率       | 團隊在同一份簡報上同時編輯                 | vague claim became what happens |
| 不是工具太多，而是流程不清       | 流程不清，工具才越買越多                   | not X but Y                     |
| 上線 → 驗證 → 回報               | 先上線，再驗證，最後回報                   | arrow became verbs              |
| 降低成本;提升品質                | 成本下降，品質上升                         | semicolon                       |
| 客戶導向、數據驅動、敏捷創新     | 客戶回饋決定下一版的順序                   | invented trio                   |
| Tickets were closed by support   | Support closed the tickets                 | passive                         |
| Rollout — pilot, scale, optimize | The pilot ran first, then the full rollout | em dash and trio                |
